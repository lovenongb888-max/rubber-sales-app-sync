# บันทึกแบรนด์ Rubber

โลโก้ Rubber ใช้ใบยางพาราสีเขียวแบบเวกเตอร์ร่วมกับหยดน้ำยางสีครีมบนพื้นสีเขียวเข้ม เพื่อสื่อถึงผลผลิตยางพาราและการบันทึกข้อมูลการขายอย่างเรียบง่าย สัญลักษณ์มีองค์ประกอบขนาดใหญ่ อ่านได้ชัดเจนเมื่อย่อเป็นไอคอนสำหรับหน้าจอหลักของอุปกรณ์

แหล่งไฟล์เว็บแบบถาวรของโลโก้คือ `/manus-storage/rubber-assets/rubber-app-icon_ea6f1590.png` และไฟล์เดียวกันถูกบีบอัดเป็นขนาด 512 × 512 พิกเซลเพื่อใช้เป็น `icon.png`, `splash-icon.png`, `favicon.png` และ `android-icon-foreground.png` ภายในโปรเจกต์แล้ว
